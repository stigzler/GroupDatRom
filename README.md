# Overview

A small app to convert flattened rom sets (as found in common sets) to one recognized by RomM (moves single-game, multi-file roms into their own folder). 

You can add what tags are considered as an identifier of a multi-file rom in `[appRoot]/MediaTypeMappings.json`

Also, can generate m3u files for supported formats (eg. .chd - but not .zip)
